# 🐤 Blink Flappy Bird

A Python-based Flappy Bird clone powered by Computer Vision. Control the bird's jump by simply **blinking your eyes** using your webcam!

Built with **Pygame**, **OpenCV**, and **MediaPipe**. Optimized for lightweight hardware (runs smoothly on integrated graphics like Intel HD 620).

---

## 🎮 How to Play

1. Make sure your face is well-lit and clearly visible to your webcam.
2. Press **SPACE** on the home screen to start.
3. **Blink your eyes** to make the bird jump!
4. Avoid hitting the green pipes and the ground.

---

## 🛠️ Prerequisites & Installation

Follow these steps to set up and run the game on **Ubuntu / Linux**:

### 1. Install System Dependencies
```bash
sudo apt update
sudo apt install -y python3.12 python3.12-venv libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev libgl1 libglx-mesa0 v4l-utils

### 📂 Repository Structure

- `blink_flappy_bird.py` - Main Python game script with OpenCV & MediaPipe integration.
- `blink_bird_save.json` - Local storage file for persisting your highest score.
- `README.md` - Setup and gameplay documentation.
